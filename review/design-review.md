# Visual simplification

Applied the installed [unslop skill](https://github.com/heydamir/unslop/tree/main/skills/unslop), by Damir Sokolovsky, CC BY 4.0. Credit is retained here and in the stylesheet. The user’s request for a plain study site determines the direction.

- Product: French reference and practice for English-speaking learners.
- Character: practical, readable and restrained.
- Reference: a course contents page and reference book.
- Emphasis: actual French examples and revealed answers.
- Identifying detail: numbered lessons paired with source dates.

Removed decorative artwork, slogans, oversized serif headings, tracked uppercase labels, shadows, elaborate panels and ornamental motion. Applied system typography, white/neutral surfaces, one blue accent, simple lesson rows and compact navigation. Long lessons have a small section index. Tables scroll within their own region on narrow screens.

Browser checks exercised model-answer quizzes, scoring, a lesson-specific worked-example deck and reveal. Responsive library evidence is in library-preview.jpg. A temporary 390-pixel viewport check reported no document-level horizontal overflow; the viewport override was reset afterward. Three visual captures were used in total, including the initial inspection.
